# FF Non-Cheating Automation with Brevent

A collection of safe, non-cheat automation scripts for Free Fire using Brevent. These scripts help with accessibility, convenience, and reducing repetitive tasks without violating game ToS.

## Features

- **Quick Settings Toggle**: Rapidly toggle WiFi, Bluetooth, and display settings
- **Auto-Restart Game**: Detect crashes and automatically restart
- **Notification Manager**: Auto-dismiss notifications during gameplay
- **Performance Monitor**: Log FPS and lag metrics
- **Macro Gestures**: Record and playback navigation gestures (menu navigation only)
- **AFK Detector**: Detect inactivity and save battery

## What This Is NOT

❌ This is NOT an aimbot or aim assist  
❌ This does NOT automate in-game actions  
❌ This does NOT modify game mechanics  
❌ This will NOT get you banned

## What This IS

✅ Device automation for convenience  
✅ System-level tweaks using Brevent  
✅ Accessibility helpers  
✅ Performance monitoring  
✅ Non-gameplay automation

## Installation

1. Install [Brevent](https://brevent.kotlin.app/) on your Android device
2. Clone this repository
3. Follow individual script instructions in `/scripts/` folder

## Requirements

- Android 5.0+
- Brevent app installed
- Device with USB debugging enabled (or manual setup)
- Free Fire installed (optional, scripts work on device level)

## Usage

Each script folder contains:
- `script.brevent` - The automation script
- `config.json` - Configuration options
- `README.md` - Usage instructions

## Scripts Included

### 1. Quick Settings
Quickly toggle device settings without entering Settings app.

### 2. Game Crash Recovery
Auto-detects game crashes and restarts automatically.

### 3. Notification Blocker
Suppresses non-critical notifications during gameplay.

### 4. Performance Logger
Logs device performance metrics for troubleshooting lag.

### 5. Menu Navigator
Records macro gestures for navigating menus (non-gameplay only).
